## 手順
1. 下の「順番表」で、まだ PR も `issue-<番号>` ブランチも無い最初の Issue を1つ取る（`gh issue view <番号>` で本文だけ読む。Issue の一覧は取らない）。
2. **エージェントは1つだけ**で進める（並行しない）。
3. ブランチ `issue-<番号>` で作業し、PR を1つ作る。PR 本文に `Closes #<番号>`（残りがあるなら `Refs #<番号>`）と件数、飛ばした種。
4. PR を出したら**そこで止まる**。レビュー待ちや次の Issue の確認のために待たない。続きは人が「続き」と言ったときに 1 から。

## トークンを使わない決まり（必ず守る）
- 読まないファイル: `data/species_master.csv`、`app/data/*.json`、`data/*/photos/`、`data/*/photo_scores.csv`、`ROADMAP.md`。種の一覧が要るときは `python3 scripts/worklist.py <科スラグ>` を使う。
- 読むのは: このファイル、取った Issue の本文、その Issue が指す `tasks/` の1ファイルだけ。
- コマンドの出力は短く（`| tail -3`）。`git diff` や生成された JSON を表示しない。
- 1回の作業は **最大40種**。40種で PR を出して止まる。
- Web は1種につき1ページまで（FishBase の種ページ）。そこに無ければその種は飛ばす。検索のやり直しはしない。
- 画面確認（ブラウザ起動・スクリーンショット）はしない。
