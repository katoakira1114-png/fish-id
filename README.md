# fish-id

八重山（石垣島・西表島）の魚を同定する私的アプリのデータ作成プロジェクトです。
Gemini と Claude で分担して進めます。

## プロジェクト構成

- `tasks/` : 作業指示書を1件1ファイルで置く場所
- `data/pomacentridae/traits.csv` : スズメダイ科の形質表
- `data/pomacentridae/drafts/` : Gemini が作成する下書き（1種1ファイルの JSON）

## 分担ルール

- **1作業 = 1ブランチ = 1プルリクエスト**: PR の説明に、埋めた件数と自信のない種を書く。
- **main には直接 push しない**（最初のセットアップだけ例外）。
- **Claude が PR を確認して直し、マージする**。
- **私的利用のみ**: 画像は URL で参照し、リポジトリに画像を保存しない。
